# 清理助手

扫描当前环境，找出多余的、重复的、低质量的插件/MCP/Skill/Hooks，推荐卸载。

## 执行流程

### 1. 全量扫描当前环境

不要写死路径。先判断当前用的是什么工具（Claude Code、OpenCode、Cursor 等），然后用对应的文档代理查询该工具的配置文件位置和管理方式。

查询内容：
- 已安装的插件列表和启用状态
- 已配置的 MCP 服务器（注意不同作用域：用户级、项目级、local 等）
- 已安装的 Skill 和 commands
- Hooks 和 rules 配置

确保不遗漏任何作用域的配置。

### 2. 逐项分析

对每个已安装的项目，从以下维度评估：

**冗余性** — 工具本身是否已有等效的内置功能？
- 比如：某些 MCP 提供的功能工具自己就能做（文件操作、搜索、git 等）
- 比如：某些 skill 的功能已经被其他插件覆盖

**活跃度** — 这个插件/MCP 还在维护吗？
- GitHub 仓库最后更新时间
- issue 是否有回应
- 是否已过时或被更好的替代品取代

**使用频率** — 从配置和上下文推断是否真的在用
- 配置了但从未出现在会话中的 MCP 工具
- 装了但没有触发过 skill

**冲突/重叠** — 是否有多个工具做同一件事？
- 多个 GitHub 相关工具
- 多个代码格式化工具
- 功能高度重叠的 LSP 插件

**性能影响** — 是否拖慢启动或占用资源？
- stdio 类型的 MCP 每次启动都会拉起进程
- 过多的插件增加上下文长度

### 3. 输出清理报告

格式：

```markdown
## 环境概览
- 已安装插件：X 个
- 已配置 MCP：X 个
- 已安装 Skill：X 个
- 已配置 Hooks：X 个

## 推荐卸载

### 🔴 冗余（工具已有等效功能）
| 名称 | 类型 | 原因 |
|---|---|---|
| xxx | MCP | 内置的 xxx 工具已覆盖此功能 |

### 🟡 重叠（多个工具做同一件事）
| 名称 | 类型 | 原因 |
|---|---|---|
| xxx | 插件 | 与 yyy 功能重叠，建议保留更活跃的那个 |

### 🟡 不活跃/低质量
| 名称 | 类型 | 原因 |
|---|---|---|
| xxx | MCP | GitHub 6 个月未更新，issue 无人回复 |

### ⚪ 可选清理（影响性能或增加上下文）
| 名称 | 类型 | 原因 |
|---|---|---|
| xxx | 插件 | 每次会话加载但很少使用 |

## 建议保留
| 名称 | 类型 | 原因 |
|---|---|---|
| xxx | 插件 | 活跃维护，功能无替代 |
```

### 4. 提供卸载命令

对每个推荐卸载的项目，给出具体的卸载命令。但不要自动执行，等用户确认。

## 注意事项

- 只推荐，不自动卸载
- 对不确定的项目标注"需人工确认"，不要误判
- 如果某个插件用户明显在用（比如当前会话中出现过），不要推荐卸载
- 用 WebSearch 验证插件的活跃度和质量
