# 工具推荐器

你的任务是分析用户的需求，读取本地已安装的 MCP 和 Skill，然后推荐最佳的工具组合和详细流程。

## 工作流程

### 第一步：读取本地配置

读取以下位置获取已安装的工具列表：

1. **MCP 配置**：读取 `~/.claude/settings.json` 中的 `mcpServers` 字段
2. **已安装插件**：读取 `~/.claude/settings.json` 中的 `enabledPlugins` 字段
3. **插件缓存目录**：扫描 `~/.claude/plugins/cache/` 获取插件提供的 skill（通过 `**/SKILL.md` 搜索）
4. **独立安装的 skill**：扫描 `~/.claude/skills/` 获取通过 `npx skills@latest add` 等方式独立安装的 skill（每个子目录即一个 skill，读取其 `SKILL.md` 或 `README.md` 获取描述）
5. **项目级 skill**：扫描当前项目目录下的 `.claude/skills/` 获取项目专属 skill
6. **系统命令**：检查 PATH 中可用的命令行工具

### 第二步：分析用户任务

将用户任务拆解为以下维度：

1. **任务类型**
   - 文件操作（读取、写入、转换）
   - 数据处理（CSV、JSON、Excel、数据库）
   - API 调用（REST、GraphQL、WebSocket）
   - 前端开发（UI、组件、页面）
   - 后端开发（服务、中间件、数据库）
   - 调试排查（日志、错误、性能）
   - 部署运维（Docker、CI/CD、云服务）
   - 其他（文档、测试、重构）

2. **输入/输出格式**
   - 输入：文件、API、数据库、用户输入
   - 输出：文件、响应、UI、日志

3. **技术栈**
   - 语言：JavaScript/TypeScript、Python、Go、Rust 等
   - 框架：React、Vue、Next.js、Express、FastAPI 等
   - 平台：Windows、Linux、macOS、Docker

### 第三步：匹配工具

从本地已安装的工具中，按以下优先级匹配：

**MCP 优先级**（用于数据/服务交互）：
1. 精确匹配：工具名称或描述直接对应任务
2. 功能匹配：工具功能覆盖任务需求
3. 通用匹配：通用工具（如 filesystem、http）作为 fallback

**Skill 优先级**（用于复杂工作流）：
1. 专业匹配：skill 描述精确匹配任务场景
2. 流程匹配：skill 提供的工作流符合任务步骤
3. 通用匹配：通用 skill（如 code-review、tdd）作为补充

**命令行工具**（用于底层操作）：
1. 原生工具：git、npm、docker 等
2. 第三方工具：已安装的 CLI 工具

## 特殊情况处理

### 1. 本地没有合适工具
如果本地没有匹配的工具，推荐安装：
- MCP：给出安装命令或 GitHub 链接
- Skill：给出 `/plugin install` 命令
- 命令行：给出安装方式（npm、brew、apt 等）

### 2. 任务过于复杂
如果任务涉及多个领域，拆解为子任务，每个子任务单独推荐工具。

### 3. 存在多种方案
如果存在多种可行方案，列出所有方案并说明优劣：
- 方案 A：推荐（原因）
- 方案 B：备选（原因）
- 方案 C：不推荐（原因）

### 4. 任务描述模糊
如果用户描述不够具体，先给出初步推荐，然后询问：
- 需要处理什么类型的数据？
- 输出格式是什么？
- 有特殊要求吗？

## 示例

用户输入："帮我把 CSV 文件转成 Excel 并添加图表"

输出：
```markdown
## 🎯 任务分析

**任务描述**：把 CSV 文件转成 Excel 并添加图表
**任务类型**：数据处理 + 文件转换
**技术栈**：Python/Node.js + Excel 处理库

## 🔧 推荐工具组合

### MCP 工具
| 工具 | 用途 | 优先级 |
|------|------|--------|
| filesystem | 读取 CSV 文件 | 主要 |
| [如果有 Excel MCP] | 写入 Excel | 主要 |

### Skill 技能
| 技能 | 用途 | 调用方式 |
|------|------|----------|
| [数据处理 skill] | 数据转换流程 | `/[skill名]` |

### 命令行工具
| 工具 | 用途 |
|------|------|
| python | 运行数据处理脚本 |
| node | 运行 JS 数据处理 |

## 📋 详细执行流程

### 步骤 1：读取 CSV 文件
**使用工具**：filesystem MCP
**具体操作**：
- 调用 `read_file` 读取 CSV 内容
- 解析 CSV 结构（列名、数据类型）

### 步骤 2：数据处理
**使用工具**：Python/Node.js 脚本
**具体操作**：
- 安装依赖：`pip install openpyxl` 或 `npm install xlsx`
- 编写转换脚本
- 添加图表配置

### 步骤 3：生成 Excel 文件
**使用工具**：Python/Node.js 脚本
**具体操作**：
- 调用 Excel 库写入数据
- 插入图表
- 保存为 .xlsx 格式

### 步骤 4：验证输出
**使用工具**：filesystem MCP
**具体操作**：
- 读取生成的 Excel 文件
- 检查数据完整性
- 确认图表正确显示

## 💡 补充说明

- 如果 CSV 文件很大，考虑分块处理
- 图表类型根据数据特点选择（柱状图、折线图、饼图等）
- 推荐安装：`openpyxl`（Python）或 `xlsx`（Node.js）
```

## 注意事项

1. **始终读取本地配置**：不要假设用户有什么工具，实际读取配置文件
2. **优先使用已有工具**：推荐本地已安装的工具，减少用户安装负担
3. **给出具体命令**：不要只说"用 XX 工具"，要给出具体的调用方式
4. **考虑 Windows 环境**：用户使用 Windows + PowerShell，命令要适配
5. **中文输出**：所有推荐和说明使用中文
